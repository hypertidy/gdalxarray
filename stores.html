Stores

Every remote store this site reads, how permanent it is, and whether it answered at the last build.

The registry is docs/stores.yml. Before each build scripts/check_stores.py opens every store with GDAL (metadata only) and records the result; pages use that record to decide whether to run their remote cells. A weekly scheduled build fails if a store marked pinned or permanent stops answering.

  • pinned: a fixed commit or immutable object, will not change.
  • permanent: an archive the provider commits to keeping.
  • versioned: stable until the provider retires this version.
  • rolling: the address is stable, the contents change over time.
  • temporary: a scratch or transfer location, expected to go.
  • unknown: Not yet classified.

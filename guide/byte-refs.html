Byte-reference stores

A multidim VRT mosaic over netCDF, the byte table behind it, and kerchunk-Parquet Zarr.

Many archives are thousands of netCDF or HDF5 files. Two ways to read such a collection as one array, without copying it:

  • a multidimensional VRT (gdal mdim mosaic) stitches the files along a dimension, and GDAL reads each file through its own driver;
  • a byte-reference table records, for every chunk of every array, which file holds it and at what byte offset and size; any reader that knows the codec can then fetch chunks directly. kerchunk’s Parquet references are one form of this; the table below is another.

Both are small text or tabular artifacts that describe data rather than holding it.

time arrives as plain numbers here because gdal mdim mosaic carries the values over but not their units, so xarray has nothing to decode them with. Opening one of the source files directly gives decoded times; the Virtual paths page does that.

The byte table

The same three files, described chunk by chunk. The table was read from the files with GDAL (MDArray.GetRawBlockInfo) when the fixture was built, and GDAL’s Parquet driver reads it back:

def read_table(path):
    ds = gdal.OpenEx(path, gdal.OF_VECTOR)   # keep the dataset alive while
    lyr = ds.GetLayer(0)                      # its layer is in use
    defn = lyr.GetLayerDefn()
    cols = [defn.GetFieldDefn(i).GetName() for i in range(defn.GetFieldCount())]
    return pd.DataFrame([{c: f.GetField(c) for c in cols} for f in lyr])

refs = read_table(data("oisst/refs_sst.parquet"))

One row per chunk: the chunk’s index along each dimension, the file it lives in, its byte offset and size, and how it is encoded, as GDAL reports it. OISST stores each day’s field as a single chunk:

tables = {t["file"]: t for t in data_json("oisst/provenance.json")["products"]["byte_tables"]}
chunks = tables["refs_sst.parquet"]["chunks"]
dict(zip(tables["refs_sst.parquet"]["dims"], chunks))
{'time': 1, 'zlev': 1, 'lat': 720, 'lon': 1440}

Decoding a chunk by hand

With a row of the table, a chunk is a range read and whatever the info column lists: here a zlib inflate and a byte unshuffle. No netCDF library is involved:

row = refs.iloc[1]
info = set(x.strip() for x in row["info"].split(";"))
print(sorted(info))

f = gdal.VSIFOpenL(data("oisst/" + row["path"]), "rb")
gdal.VSIFSeekL(f, int(row["offset"]), 0)
raw = gdal.VSIFReadL(1, int(row["size"]), f)
gdal.VSIFCloseL(f)

buf = zlib.decompress(raw) if "COMPRESSION=DEFLATE" in info else raw
itemsize = 2                                              # int16
if "FILTER=SHUFFLE" in info:                               # bytes grouped by position
    n = len(buf) // itemsize
    buf = np.frombuffer(buf, np.uint8).reshape(itemsize, n).T.copy().tobytes()
order = "<" if "ENDIANNESS=LITTLE" in info else ">"
chunk = np.frombuffer(buf, f"{order}i2").reshape(chunks)
f"{len(raw):,} bytes on disk, {chunk.nbytes:,} bytes decoded, shape {chunk.shape}"
['COMPRESSION=DEFLATE', 'ENDIANNESS=LITTLE', 'FILTER=SHUFFLE']
'667,794 bytes on disk, 2,073,600 bytes decoded, shape (1, 1, 720, 1440)'

and it matches what gdalxarray reads through the VRT, value for value:

via_gdal = xr.open_dataset(vrt, engine="gdalxarray", mask_and_scale=False)["sst"].isel(time=1).values
assert np.array_equal(chunk[0], via_gdal)
bool(np.array_equal(chunk[0], via_gdal))
True

That equality is what makes a byte table a faithful replacement for the files’ own metadata: the files can stay where they are, and the table travels.

kerchunk-Parquet Zarr

GDAL’s Zarr driver reads kerchunk references stored as Parquet, so a reference store opens like any Zarr. This one is a pinned commit of the BRAN2023 ocean reanalysis temp variable: about 13 TB of netCDF on NCI’s THREDDS server, described by a few megabytes of Parquet on GitHub.

NoteLive: BRAN2023 ocean temp as kerchunk-Parquet Zarr (GitHub, pinned commit)
  • Address: ZARR:"/vsicurl/https://raw.githubusercontent.com/mdsumner/virtualized/d0b9c23317d2de07c3851eb9dfc968be1761d5b8/zarr/ocean_temp.zarr"
  • Provider: mdsumner/virtualized at d0b9c23; chunks on NCI THREDDS
  • Pinned: a fixed commit or immutable object, will not change.
  • Status: answered the store check at 2026-10-27 18:03 UTC.
if live("bran-virtualized-pinned"):
    bran = xr.open_dataset(store("bran-virtualized-pinned")["dsn"], engine="gdalxarray",
                           drop_variables=["Time_bnds"])
    print(f"{bran['temp'].nbytes / 1e12:.1f} TB described; dims {dict(bran.sizes)}")
    print(bran["temp"].encoding.get("preferred_chunks"))

Reading values fetches the referenced byte ranges from THREDDS, which rate-limits parallel requests; the BRAN2023 gallery page shows that read and the settings it needs.

Warping

gdalxarray.warp() builds a warped-VRT recipe; xarray opens it lazily.

gdalxarray.warp() wraps gdal.Warp(..., format="VRT") and returns the VRT as a string. Nothing is resampled until values are read, and then only for the cells asked for. The recipe is a few kilobytes whatever the size of the source.

Antarctic sea ice to longitude and latitude

One day of Antarctic sea-ice concentration from satellite passive microwave (the NOAA/NSIDC climate data record), on the grid it is published on: 25 km polar stereographic cells on the Hughes 1980 ellipsoid (EPSG:3412, not the WGS84-based EPSG:3031). Land, coast and the pole hole are nodata.

Extra keywords go straight to gdal.WarpOptions, so cutlines, transformer options, geolocation arrays, working type and so on are available. Curvilinear grids uses geoloc=True.

Checked against GDAL

scripts/fixtures/make_warp.py defines target grids over these two sources (lon/lat, WGS84 polar stereographic, Equal Earth, orthographic, and two coarse cases where GDAL reads an overview) and records what gdal.Warp writes for each: into memory, single-threaded, error threshold 0.125. For each case this page compares:

  • gdalxarray: gdalxarray.warp() opened with xarray;
  • GDAL VRT: the same warped VRT read by GDAL itself (gdal.Warp(format="VRT") then ReadAsArray);
  • GDAL direct: gdal.Warp into memory with the same settings as the recorded case, using the GDAL this page was built with;
  • pinned: the recorded result, from the GDAL version in the manifest.

gdalxarray must agree with the GDAL VRT on every cell: that is the claim this package makes, that it adds nothing to what GDAL reads. The other two columns are reported, not required. A warped VRT computes each block on its own, so where the approximate transformer struggles (near a pole, say) it can differ from a single direct warp; and GDAL’s resampling kernels can change between releases.

def same(a, b):
    return float(np.mean((a == b) | (np.isnan(a) & np.isnan(b)))) if a.dtype.kind == "f" \
        else float(np.mean(a == b))

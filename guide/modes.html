Open modes

Classic rasters (bands as a dimension or as variables) and multidimensional arrays.

gdalxarray opens a source in one of two GDAL data models, chosen by multidim=:

multidim=False (classic) multidim=True (default)
GDAL API gdal.Open, raster bands gdal.OpenEx(..., OF_MULTIDIM_RASTER), groups and arrays
Dimensions (band, y, x) whatever the source names: time, depth, lat, lon, …
Georeferencing geotransform + CRS, as a RasterIndex and CRSIndex coordinate arrays from the source
Natural for GeoTIFF/COG, JPEG2000, classic VRT, warped VRT netCDF, HDF5, Zarr, GRIB, multidim VRT, Icechunk

Classic, bands as a dimension

The default for multidim=False: one band_data variable with dimensions (band, y, x), the layout rioxarray uses. The example is a cloud-free Sentinel-2 summer scene over Hobart, from kunanyi / Mount Wellington to the Derwent estuary: four bands (blue, green, red, near infrared) on the scene’s own UTM zone 55S grid, averaged to 20 m.

Data: Copernicus Sentinel-2 Level-2A surface reflectance; licence: Copernicus Sentinel data terms (free and open); attribution: contains modified Copernicus Sentinel data; day 2024-12-04. Built by scripts/fixtures/make_sentinel2.py; details in docs/fixtures/sentinel2/provenance.json.

src = data("sentinel2/" + data_json("sentinel2/provenance.json")["file"])

The bands are stored as integers with a scale and offset (Sentinel-2 L2A digital numbers); with the default mask_and_scale=True they arrive as surface reflectance, with nodata masked:

ds["band_data"].encoding.get("scale_factor"), ds["band_data"].encoding.get("add_offset"), \
    float(ds["band_data"].mean())
(0.0001, -0.1, 0.08045086261333333)

Ordinary xarray operations apply. A true-colour composite is a selection and reordering along band:

rgb = ds["band_data"].sel(band=[3, 2, 1])               # red, green, blue
rgb = (rgb / rgb.quantile(0.98)).clip(0, 1).transpose("y", "x", "band")
fig, ax = plt.subplots(figsize=(8, 6.7))
rgb.plot.imshow(ax=ax, rgb="band")
ax.set_aspect("equal")
ax.set_title("true colour, " + data_json("sentinel2/provenance.json")["day"])
ax.set_xlabel("easting (m)"); ax.set_ylabel("northing (m)")
plt.show()

Classic, bands as variables

band_as_dim=False makes each band its own variable, named from the band description (or band_N when there is none). This suits rasters whose bands are different quantities, and makes band arithmetic read like the quantities it combines:

dsv = xr.open_dataset(src, engine="gdalxarray", multidim=False, band_as_dim=False)
list(dsv.data_vars), dsv["nir"].dims
(['blue', 'green', 'red', 'nir'], ('y', 'x'))
ndvi = (dsv["nir"] - dsv["red"]) / (dsv["nir"] + dsv["red"])
fig, ax = plt.subplots(figsize=(8, 6.7))
ndvi.plot(ax=ax, cmap="RdYlGn", vmin=-0.5, vmax=0.9, cbar_kwargs={"label": "NDVI"})
ax.set_aspect("equal"); ax.set_title("NDVI")
ax.set_xlabel("easting (m)"); ax.set_ylabel("northing (m)")
plt.show()

Dimensions, coordinates and attributes come from the store, so selection reads like the model’s own description:

fig, axs = plt.subplots(1, 2, figsize=(7, 4.5), sharey=True, layout="constrained")
for ax, k, name in [(axs[0], -1, "surface"), (axs[1], 0, "bottom")]:
    roms["temp"].isel(s_rho=k).plot(ax=ax, cmap="RdYlBu_r", vmin=float(roms.temp.min()),
                                     vmax=float(roms.temp.max()), add_colorbar=(k == 0))
    ax.set_title(f"{name} (s_rho = {float(roms.s_rho[k]):.2f})")
plt.show()

Placing these cells on the earth uses the 2D lon_rho and lat_rho arrays; see Curvilinear grids.

Checked against GDAL

The three Zarr fixtures in wxylib/fixtures hold the same pixels as three of the COGs, and their manifest lists windows whose values GDAL read with osgeo.gdal. gdalxarray must give the same numbers through xarray indexing, in both modes:

man = fixture_json("zarr/manifest.json")
rows = []
for case in man["cases"]:
    path = fixture("zarr/" + case["store"])
    md = xr.open_dataset(path, engine="gdalxarray", mask_and_scale=False)[case["array"]]
    cl = xr.open_dataset(f'ZARR:"{path}":/{case["array"]}', engine="gdalxarray",
                         multidim=False, mask_and_scale=False)["band_data"]
    for w in case["windows"]:
        win = dict(y=slice(w["row"], w["row"] + w["height"]),
                   x=slice(w["col"], w["col"] + w["width"]))
        expect = fixture_array("zarr/" + w["file"], case["dtype"])
        a = md.isel(**win).values
        b = cl.isel(**win).values
        ok_md = np.array_equal(a.ravel(), expect)
        ok_cl = np.array_equal(b.ravel(), expect)
        rows.append((case["store"], w["file"].rsplit("/", 1)[-1], a.shape, ok_md, ok_cl))
        assert ok_md and ok_cl, (case["store"], w["file"])
